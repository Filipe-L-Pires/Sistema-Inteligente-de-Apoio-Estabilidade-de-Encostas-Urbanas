SIAEU — Sistema Inteligente de Apoio à Estabilidade de Encostas Urbanas
O SIAEU é uma plataforma técnica integrada voltada para a análise, prevenção e monitoramento de riscos geotécnicos em áreas urbanas. Desenvolvido como Trabalho de Conclusão de Curso (TCC) em Engenharia Civil na UNISUAM (2026/1), o sistema une cálculos de engenharia tradicional com monitoramento em tempo real.

📋 Sobre o Projeto
Os deslizamentos são responsáveis por mais de 40% dos óbitos em desastres naturais no Brasil. O SIAEU visa mitigar esse cenário através de uma interface inteligente que permite a gestores, engenheiros e órgãos como a Defesa Civil tomarem decisões baseadas em dados.

Área de Estudo
O foco inicial do projeto é a Encosta R3 (Alto Risco), localizada na Zona Norte do Rio de Janeiro.

Geologia: Gnaisse facoidal com foliação subparalela.

Declividade média: 38° com altura aproximada de 80m.

Vegetação: 60% da cobertura vegetal suprimida.

🚀 Funcionalidades Principais
Simulador de Estabilidade (FS): Calculadora baseada no Método do Talude Infinito para determinar o Fator de Segurança sob diferentes condições (Seco/Saturado).

Dashboard IoT: Monitoramento ao vivo de sensores em campo (umidade do solo, pluviometria e inclinação).

Mapa de Risco Geotécnico: Visualização espacial dos setores críticos baseada em dados da Geo-Rio.

Galeria Técnica & Biblioteca: Repositório de documentos normativos (NBR 11682, NBR 10844) e memoriais descritivos de intervenções como DHP e Gabião.

🛠️ Tecnologias Utilizadas
Frontend: HTML5, CSS3 (Modern UI com variáveis root e Glassmorphism), JavaScript (ES6+).

Gráficos: Chart.js para visualização de dados de sensores.

Design: Ícones em SVG e tipografia técnica (JetBrains Mono e Exo 2).

🏗️ Parâmetros Geotécnicos de Referência
O sistema opera com parâmetros rigorosos conforme a NBR 11682:2009:

Solo Residual: c'=12kPa | φ'=30° | γ=19kN/m³.

Fator de Segurança Mínimo (Saturado): ≥ 1,30.

Fator de Segurança Mínimo (Estático): ≥ 1,50.
